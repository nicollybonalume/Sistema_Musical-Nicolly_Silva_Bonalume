# 🎵 Sistema Musical

## 🎯 Objetivo
Desenvolver uma página web que permita cadastrar músicas, artistas e explorar diferentes gêneros musicais, utilizando os conceitos fundamentais de desenvolvimento web.

## 💻 Tecnologias utilizadas
- **HTML5:** estruturação das páginas.
- **CSS3:** estilização, cores, fontes e organização dos elementos.


```

## ✨ Funcionalidades
- Página inicial com apresentação da biblioteca.
- Exibição de músicas e artistas.
- Organização por gêneros musicais.
- Layout visual organizado.
- Design adaptável a diferentes telas (caso implementado).

## 🚀 Como executar
1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Localize o arquivo `index.html`.
4. Abra-o em um navegador.
